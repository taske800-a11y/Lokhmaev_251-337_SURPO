1. Как объявить поле, доступное только внутри класса?

private int age;


Поле будет доступно только внутри класса, в котором оно объявлено.

2. Как объявить тип, доступный во всей сборке, но не за её пределами?

internal class Product { }


Класс будет доступен внутри текущей сборки, но недоступен из других сборок.

3. Как объявить вспомогательный тип, доступный только в одном файле?

file static class PriceFormatter { }


Класс будет доступен только в том файле, где он объявлен.

4. Как объявить метод, доступный наследникам класса?

protected void SetPrice(int price) { }


Метод будет доступен внутри самого класса и в его классах-наследниках.

5. Что случится при попытке унаследоваться от типа, помеченного file?

Компилятор выдаст ошибку, поскольку тип с модификатором file доступен только внутри файла, в котором объявлен.

6. Какой принцип SOLID нарушен, если Catalog внутри себя создаёт new FileProductRepository("products.csv")?
private readonly IProductRepository repository;


Нарушается принцип DIP (Dependency Inversion Principle) — принцип инверсии зависимостей. Класс должен зависеть от абстракции (интерфейса), а не от конкретной реализации.

7. Какой принцип SOLID нарушен, если Product умеет и хранить данные, и сохранять их в файл, и печатать отчёт?

public class Product { }


Нарушается принцип SRP (Single Responsibility Principle) — принцип единственной ответственности. Класс должен отвечать за одну задачу, а сохранение файлов и печать отчётов должны находиться в отдельных классах.
